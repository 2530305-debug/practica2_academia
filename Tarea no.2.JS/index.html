introduccion y contexto

1. ¿que es javascript y cuales son sus principales usos en la web?
JavaScript es un lenguaje de programación interpretado, esto quiere decir que necesita de un intérprete para su ejecución. En la mayoría de los casos es interpretado gracias a los navegadores, como Chrome, Edge o Firefox.
JavaScript sirve para crear de todo un poco:

  • Páginas web: diseña la parte visual, haciendo que los sitios sean interactivos y animados.
  • Servidores: controla la lógica interna y las bases de datos de una web.
  • Aplicaciones móviles: permite crear apps para celulares.
  • Videojuegos: permite hacer juegos sencillos que funcionan directo en el navegador, sin instalar nada.

2. ¿en que año y con que proposito se creo javascript?
JavaScript fue creado en 1995 por Brendan Eich; su objetivo era permitir interactividad en las páginas web, algo revolucionario para la época. En solo 10 días, Eich desarrolló la primera versión, que se integró en el navegador Netscape Navigator.

3. ¿por que javascript no es lo mismo que java?
Java es pesado y estructurado, usado para construir los motores de aplicaciones grandes como las de un banco o Android. JavaScript es ligero y ágil, pensado para ponerle botones interactivos, animaciones y color a los sitios web.

4. ¿como se complementa javascript con html y css?
Los tres lenguajes son parte integrante de la creación de una página web funcional y visualmente atractiva. HTML proporciona el contenido y la estructura, CSS añade el diseño y el estilo, y JavaScript aporta elementos interactivos.

fundamentos del lenguaje

5. ¿cual es la sintaxis basica de javascript y como se escriben comentarios?
Variables: hoy en día se usan principalmente let (valores que cambian) y const (valores fijos).

const nombre = "Ana"; // No cambia
let edad = 25;         // Puede cambiar

Estructuras de control: se usan condiciones (if) y bucles (for, while).

if (edad >= 18) {
  console.log("Es mayor de edad");
} else {
  console.log("Es menor de edad");
}

Funciones: bloques de código que realizan una tarea específica.

function saludar(persona) {
  return "¡Hola, " + persona + "!";
}
saludar("Ana");

Comentarios: una línea con //, varias líneas entre /* y */.

6. ¿que diferencias hay entre var, let y const?

  • var y let: permiten cambiar su valor en cualquier momento.
  • const: es una constante; una vez asignado el valor no se puede volver a asignar (dará error).

7. ¿cuales son los tipos de datos primitivos en javascript? da un ejemplo de cada uno.

  • String: cadenas de texto. Ej: const nombre = "Carlos";
  • Number: valores numéricos, enteros o con decimales. Ej: const precio = 19.99;
  • Boolean: true o false. Ej: const esMayorDeEdad = true;
  • Undefined: variable declarada sin valor asignado. Ej: let valor;
  • Null: ausencia intencional de valor. Ej: const respuestaServidor = null;
  • Symbol: identificador único e irrepetible. Ej: const idUnico = Symbol("id");

8. ¿que diferencia hay entre un array y un objeto en javascript?

  • Un array es como una lista del supermercado: importa el orden y se busca por posición. Usa corchetes.
  • Un objeto es como una ficha de información: guarda datos etiquetados con un nombre. No importa el orden. Usa llaves.

control de flujo

10. ¿como funcionan las sentencias condicionales if, else y switch?

  • if: evalúa una condición; si es verdadera, ejecuta su bloque.
  • else if: si la anterior fue falsa, evalúa una nueva condición opcional.
  • else: caso por defecto, se ejecuta si ninguna condición anterior fue verdadera.

11. ¿cuales son las diferencias entre los bucles for, while y do...while?

  • for: cuando sabes exactamente cuántas veces repetir la acción.
  • while: cuando no sabes cuántas veces se repetirá; evalúa la condición ANTES de ejecutar el código.
  • do...while: igual que while, pero evalúa la condición DESPUÉS, así que el bloque se ejecuta al menos una vez.

12. ¿para que sirven las palabras clave break y continue?
break cancela el ciclo por completo, como un freno de emergencia. continue solo se salta el paso actual y sigue con el siguiente sin detener el proceso.

funciones

13. ¿como se declara una funcion y como se llama en javascript?
La forma clásica usa la palabra reservada function seguida del nombre:

function saludar(nombre) {
  return "¡Hola, " + nombre + "!";
}

14. ¿que significa que una funcion tenga parametros y un valor de retorno?
Los parámetros son los datos que entran a la función para que pueda trabajar. El valor de retorno es el resultado final que la función devuelve al terminar.

15. ¿que son las funciones flecha (=>) y que ventajas tienen?
Son una sintaxis más corta y moderna para crear funciones. Reducen el código al no requerir la palabra function ni return en líneas simples.

16. ¿que es el scope en javascript y como afecta a las variables?
El scope es la zona del código donde una variable existe y se puede usar; fuera de ahí, JavaScript no la encuentra.

  • let y const: scope de bloque, quedan encerradas en el {} o función donde se crearon.
  • var: ignora los bloques {} y solo respeta el scope de función, por eso puede causar errores.

objetos y colecciones

17. ¿como se declara un objeto y como se accede a sus propiedades?
Un objeto es una ficha de datos entre llaves {} con parejas nombre: valor.

const usuario = { nombre: "Ana", edad: 25 };
console.log(usuario.nombre);   // Ana
console.log(usuario['edad']);  // 25

18. ¿que diferencia hay entre una propiedad y un metodo en un objeto?

  • Propiedad: variable guardada en el objeto, un dato o característica.
  • Método: función guardada en el objeto, una acción que puede realizar.

19. menciona al menos 3 metodos basicos de los arrays (push, pop, map, etc.) y explica como funcionan.

  • push(): agrega un elemento al final de la lista.
  • pop(): saca y elimina el último elemento.
  • map(): crea una nueva lista con cambios aplicados a cada elemento.

Ejemplo con alimentos: con push añadimos algo al carrito, con pop quitamos el último, y con map aplicamos un descuento a todos los precios.

otros temas basicos

20. ¿que es el dom y por que es importante en el uso de javascript en paginas web?
El DOM es un mapa que convierte toda la página web en elementos que JavaScript puede entender y controlar. Permite modificar textos, cambiar colores, esconder cosas o responder al instante cuando el usuario hace clic, todo sin recargar la web.

21. ¿que es un evento en javascript y menciona al menos 3 ejemplos comunes?

  • click: el usuario presiona un botón o elemento.
  • submit: se envían los datos de un formulario.
  • keydown: se presiona una tecla del teclado.

22. ¿cual es la diferencia entre alert, prompt y console.log?

  • alert(): ventana emergente para avisar algo (detiene la página hasta dar clic en Aceptar).
  • prompt(): ventana emergente para pedir un dato al usuario.
  • console.log(): mensaje oculto en herramientas de desarrollador, solo lo ve el programador.

23. ¿como se abre la consola del navegador y que ventajas tiene usarla para depurar codigo?
Se presiona F12 (o clic derecho → Inspeccionar) y se abre la pestaña Consola.

  • Te avisa de los errores: muestra el problema en texto rojo y en qué línea ocurrió.
  • Pruebas al instante: puedes escribir y probar código ahí mismo, sin guardar ni reiniciar nada.
